## Linguagem visual comum

O jogo combina desenho animado dos anos 1930 com grandes oficinas e fábricas movidas a vapor. As formas são arredondadas e os contornos, expressivos. Os materiais principais são ferro, aço esmaltado, cobre e latão, com rebites, válvulas, tubulações e instrumentos analógicos.

O robô usa marfim, grafite e cobre, com o brilho laranja da fornalha. Peças de XP são douradas; perigos usam vermelho. O fundo tem cores mais suaves para preservar a leitura dos personagens e projéteis.

## Como consultar e ampliar

1. Leia a [visão do jogo](visao-do-jogo/README.md) para entender a composição.
2. Consulte o [herói](heroi/README.md) e sua [evolução](evolucao-heroi/README.md) para manter a identidade do personagem.
3. Use o [fundo da oficina](fundo-oficina/README.md) para orientar o cenário e as camadas.
4. Consulte a [galeria dos inimigos e do chefão](inimigos/README.md) para comparar as silhuetas e os comportamentos.
5. Ao criar outra imagem, mantenha esse padrão de pasta, explicação, imagem e prompt. Salve alterações como novas versões para permitir comparação.

Cada uma das seis pastas de inimigo contém um PNG, um `README.md` e um `PROMPT.md`.

Estas imagens são referências de conceito. A preparação para o GDevelop inclui sprites individuais, animação, braço-canhão separado e imagens independentes para as camadas do fundo, conforme descrito em cada pasta.

## Origem

Arte conceitual gerada por IA com a ferramenta de imagens integrada ao Codex, a partir das ideias e referências fornecidas pelo grupo. Os prompts estão nas respectivas pastas. O registro de autoria e uso de IA deve acompanhar a documentação da entrega.

Este catálogo é o ponto de consulta das referências selecionadas para o jogo.
