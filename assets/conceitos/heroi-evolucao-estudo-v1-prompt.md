# Herói: estudo de evolução visual v1

Imagem: `heroi-evolucao-estudo-v1.png`.

Estudo conceitual gerado por IA com a ferramenta de imagens integrada ao Codex, usando as duas imagens fornecidas pelo grupo como referências. Mostra três estágios de reparo do mesmo personagem. Ainda não é uma folha de animação nem um conjunto de sprites individuais para importar no jogo. Os estágios são uma proposta visual; os níveis que os desbloqueiam e seus efeitos na jogabilidade ainda precisam ser definidos.

## Prompt utilizado

Use case: style-transfer. Asset type: exploratory game character refinement sheet for Oficina em Pane, a side-view 2D workshop robot platform shooter. Image 1 is the character identity / refinement target: preserve this exact little robot's recognizable CRT-shaped head, blank orange screen without eyes or mouth, single bent antenna with orange bulb, ivory metal casing, charcoal flexible mechanical limbs, round orange chest core, big rounded boots, and one cylindrical arm cannon. Image 2 is a supporting reference for THREE REPAIR / EVOLUTION STAGES of this same robot, not for copying its text or backdrop. Create a fresh refined sheet of exactly three full-body versions side by side: left damaged-but-functional starter, center partially repaired, right fully restored and upgraded. Each must retain exactly the same proportions, physical height, head size, cannon length, silhouette envelope, ground baseline, right-facing near-side view, and relaxed combat-ready pose, so the stage changes could later be implemented as consistent skins in a platform game. Left has a few big readable cracked/chipped plates, a couple exposed wires and one simple patch, but a clearly readable orange screen. Middle replaces most damaged plates, retains a little wear and a visible mechanical repair seam. Right has intact yellowed ivory plates with discreet warm metal replacement seams and a restored cannon ring; remain an old workshop machine rather than futuristic armor. Change the visual rendering toward expressive hand-inked 1930s theatrical animation / rubber-hose cartoon craftsmanship suitable for a retro workshop game: flowing springy mechanical limbs, appealing weighted stance, curved asymmetry in ink contours, bold dark warm outlines, simple flat color fills with only one flat shadow tone, muted yellowed ivory and charcoal with the reference's rich orange accents. Slight hand-painted cel imperfection, very sparse wear, shapes readable at small gameplay size. Preserve a distinctly mechanical nonhuman identity; screen must stay EMPTY orange, no face, no humanoid facial features. No extra characters, accessories, gear floating beside the hero, scenery, color swatches, charts, icons, arrows, labels, typography, UI, text or watermarks. No glossy 3D rendering, airbrushed gradients, dramatic lighting, bloom, vignette or film grain across the canvas. All three figures separate, generously spaced and completely visible, no overlap, not cropped, with clean transparent alpha background, no paper backing, no ground shadows. This is a visual direction comparison, not an animation sprite sheet.
